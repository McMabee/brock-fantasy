## Data freshness and completeness

Brock Fantasy uses reviewed rosters, schedules, results, player statistics, historical records, and authorized administrative imports. The operator has selected manual updates through authorized administrators while sports API access is unavailable. Scores are not guaranteed live. Updates depend on source publication, provider access, manual review, mapping accuracy, and complete statistics.

A delay may last minutes, hours, or longer. No fixed refresh interval is guaranteed for the beta. A screen refresh does not cause an upstream source to publish new data. We keep unresolved or unapproved data unavailable rather than substituting invented figures. An absent statistic must not be assumed to be zero.

## Interpreting displayed data

The intended presentation should distinguish the following conditions and show the latest successful update time where available. These are descriptive expectations, not a claim that every screen currently displays these exact labels.

| Condition                 | Meaning                                                                                                       |
| ------------------------- | ------------------------------------------------------------------------------------------------------------- |
| Scheduled                 | A reviewed game time is available; results are not complete.                                                  |
| Provisional               | Available results or statistics may still be revised.                                                         |
| Final                     | Required inputs have completed the approved finalization process; later verified corrections remain possible. |
| Incomplete or unavailable | A required input is missing, unverified, or affected by an operational issue.                                 |
| Mapping review            | A source identity or schedule needs reconciliation before it can be used.                                     |

Rankings, average draft position, and any published projections describe the reviewed inputs and method available at the time. They may cover limited samples and are not guarantees of future performance. An unapproved prediction model must not be presented as an established forecast.

## Deadlines and corrections

Lineup and roster locks use server-recorded game times and approved league-period rules. Delayed statistics or notifications do not automatically extend deadlines or unlock players. Postponements, cancellations, rescheduling, and outage exceptions must follow published league rules; report a questionable lock to support.

Verified source revisions and authorized administrative corrections can change fantasy points, matchup outcomes, standings, and playoff implications after an earlier display. Corrections are recorded with source/reason information through the audited revision and scoring process rather than an unexplained overwrite of totals.

A published playoff advancement requires explicit audited adjudication before a correction changes it. We aim to notify affected leagues of material changes and explain the basis. A "final" result is not a promise that no subsequent verified correction can occur.

## Reporting an issue

Send support the league, game/player, disputed value, time observed, and an official source link. We review the source, mapping, rule version, and relevant revision. A report does not authorize an immediate score change, and no correction is guaranteed before your next deadline. See the [support policy](support-policy.md) for proposed response targets and the [availability notice](availability-notice.md) for interruption handling.
